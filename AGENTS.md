# AGENTS.md

Every assistant working in this repository (Claude, Cursor, Codex or another) follows [`CLAUDE.md`](CLAUDE.md)
and the three files it imports from [`rules/`](rules/). Tools that do not follow `CLAUDE.md` imports must read
those three files before starting work.

Read the relevant source before the task; the rules and procedures live here rather than being repeated in
this file:

- [Organisation rules](rules/org.md): repository ownership and where AI working material belongs.
- [Brand requests](skills/org-brand-request/SKILL.md): request missing shared tokens or assets and fulfil a request.
- [Organisation decisions](skills/org-decisions/SKILL.md): accepted decisions and their history.
- [Kit updates](skills/org-kit-update/SKILL.md): distribute a reviewed release to a consuming repository.

Other shared procedures live under `skills/org-*/SKILL.md`; read the one that fits before doing that job.
